# 功能登记表

**本文件是"功能交付状态"的唯一权威来源（SSOT）。**

- 功能**做什么**、**怎么交互**、**验收标准** → [design.md](design.md)（不在此重复）
- 功能**做到哪一步**、**归哪个里程碑** → 本文件

> 新增/删除功能时，本文件与 `design.md` 必须同时修改，规则见 [AGENTS.md](../../AGENTS.md) §3。
