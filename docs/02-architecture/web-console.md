# Web 管理界面实现规范

**本文件是"浏览器端管理界面"的唯一权威来源（SSOT）**：技术选型、布局结构、编辑器实现、调试台交互、导入导出与同步面板、状态与错误呈现。

- 提供服务的 API → [web-admin-api.md](../03-api/web-admin-api.md)
- 配置字段含义 → [config-spec.md](../03-api/config-spec.md)
- 手机端界面 → [ui-implementation.md](ui-implementation.md)

---

## 1. 定位与技术选型

浏览器端承担两件在手机上做不好的事：

1. **写配置**：键盘输入、语法高亮、错误定位、并排对照；
2. **看结果**：把解析返回值当 JSON 看，而不是当"页面"看。

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | Vue 3 + TypeScript | 与宿主应用完全解耦的纯静态产物，体积小、构建链成熟 |
| 构建 | Vite → 静态资源打入 `app/src/main/assets/webconsole/` | 无运行时依赖，离线可用 |
| 编辑器 | **Monaco Editor**（`monaco-editor` ESM + TypeScript 语言服务） | 补全/hover/签名/诊断由语言服务提供，与规范同源（[ADR-0014](adr/ADR-0014-monaco-editor-intellisense.md)） |
| 智能提示 | 注入 `config-api.d.ts`（`addExtraLib`） | d.ts 是 [config-spec](../03-api/config-spec.md) §3/§8 的派生物，改规范即改提示 |
| 状态 | Pinia | 配置列表、草稿、调试结果三块状态 |
| 请求 | 原生 `fetch` | 无需额外依赖 |
| 样式 | 原生 CSS + CSS 变量（复用应用色板语义） | 避免引入 UI 库拖体积 |

**约束**：

- 产物必须能在桌面浏览器（Chrome/Edge/Safari 近两年版本）工作；**窄屏与 WebView 降级为只读**（见 §2 断点）。
- 不使用需要 Node 运行时的能力；**Monaco 与 worker 必须本地打包，禁止 CDN**（离线可用）。
- **Monaco 只在"源码模式"按需加载**，首屏不加载。
- 控制台静态产物上限 **8MB**（含 Monaco），超出则拆独立 chunk 延迟加载。

## 2. 布局

桌面优先的三栏结构（≥ 1280px）：

```
┌──────────────┬────────────────────────────────┬─────────────────────┐
│ 配置列表      │ 编辑区                          │ 调试台              │
│ 280px        │ flex                            │ 420px               │
│              │                                │                     │
│ 搜索 / 新建   │ [表单] [源码]  tab 切换          │ 方法选择            │
│ ─────────    │ ──────────────────             │ 参数输入            │
│ ● demo       │ meta / render / behavior 分组   │ [运行]              │
│ ○ news       │ 或 JS 编辑器                    │ ─────────           │
│ ○ api        │                                │ 结果 JSON / 日志     │
│              │ 顶部工具条：保存 校验 导入 导出    │ 耗时 / 错误          │
└──────────────┴────────────────────────────────┴─────────────────────┘
```

断点：

| 宽度 | 布局 |
|---|---|
| ≥ 1280px | 三栏 |
| 900–1279px | 两栏：列表抽屉 + 编辑区；调试台改为底部可拖拽面板 |
| < 900px | 单栏 + 顶部 Tab（列表 / 编辑 / 调试），列表变抽屉；**源码模式降级为只读预览**，提示"请用桌面浏览器编辑" |

## 3. 配置列表

| 元素 | 说明 |
|---|---|
| 搜索框 | 按 key / name 模糊过滤 |
| 新建 | 弹出选择：清单形态（推荐）/ 内联形态 |
| 列表项 | 图标、名称、key、状态点（启用/停用/当前）、最近修改时间 |

选中列表项后，编辑区与调试台加载该配置；**未保存时切换需二次确认**。

## 4. 编辑区

### 4.1 双模式

| 模式 | 用途 | 行为 |
|---|---|---|
| **表单模式**（默认） | 改字段、调渲染参数 | 按 `meta` / `render` / `behavior` 分组；每字段带默认值、范围提示、枚举下拉 |
| **源码模式** | 写解析脚本、粘贴整份配置 | **Monaco** 编辑 JS（语言服务驱动）；行号、红波浪线诊断、括号匹配、折叠、多光标 |

两模式**双向同步**：表单改动即时反映到源码视图；源码语法错误时表单只读并提示"先修复语法"。

### 4.2 字段渲染规则

字段的元数据由前端内置一份 `fieldSchema`（与 [config-spec](../03-api/config-spec.md) §3 一一对应）：

| 类型 | 控件 | 校验提示 |
|---|---|---|
| string | 单行输入 | 长度、正则（`key`） |
| string（URL） | 输入 + 可点"测试打开" | 协议白名单 |
| number | 数字框 + 滑块（范围项） | 范围、整数 |
| enum | 下拉 | 白名单值 |
| boolean | 开关 | — |
| string[]（`setTags`） | 多选标签 | 白名单值 |
| object（`headers`） | 键值对表格 | 键名合法 |

**关键约束**：前端 `fieldSchema` 只是 UI 层，**判定权在服务端**（`POST /api/validate`）。前端不做最终裁决，避免两套规则分叉。

### 4.3 校验与保存

```
编辑 → 前端轻量校验（必填/格式） → 点"校验"或"保存"
     → POST /api/validate → 展示 errors/warnings
     → ok 才允许保存（POST/PUT）
```

- 错误逐条列出：`code` + 字段路径 + 人话说明 + 修复建议；
- 点击错误项**跳转到对应字段或行号**；
- `warnings` 用黄色条展示，不阻塞保存；
- 保存成功后显示"已保存 · 可试跑"，并提供"立即试跑"按钮。

### 4.4 源码编辑器（Monaco）

| 项 | 实现 |
|---|---|
| 实例 | `monaco-editor` ESM，语言 `javascript`（`typescript` 语言服务，`allowNonTsExtensions: true`） |
| 加载 | **动态 `import()`**：进入源码模式才加载；首次加载显示骨架条，避免布局跳动 |
| Worker | Vite `?worker` 方式本地打包，`MonacoEnvironment.getWorker` 指向本地 chunk，**禁止 CDN** |
| 主题 | 跟随控制台明暗；字体与字号继承阅读设置中的代码字号 |
| 编辑体验 | 行号、折叠、括号匹配、多光标、查找替换（`Ctrl/Cmd+F`）、命令面板（`F1`）、Tab 两空格、`Enter` 自动缩进 |
| 格式化 | 内置简化格式化（缩进/分号），不强制；不引入完整 prettier 以控体积 |
| 校验标记 | 语言服务诊断（红波浪线）+ 服务端 `errors[]` 映射到行号（黄/红点，见 §4.3） |
| 降级 | 宽度 < 900px 或检测到不支持 ES2020 的环境 → 只读预览 + 一键复制 |

### 4.5 智能提示（由类型定义驱动）

**原则：提示不是手写的，而是把配置规范"翻译"成一份 `.d.ts` 交给语言服务。**

```
config-spec §3（字段） ─┐
config-spec §8（注入 API） ├─► config-api.d.ts ─► addExtraLib ─► Monaco JS 语言服务
rest-contract §3（模型） ─┘                                      ├─ 补全
                                                                  ├─ hover 文档
                                                                  ├─ 参数签名
                                                                  └─ 诊断
```

| 能力 | 覆盖内容 |
|---|---|
| **补全** | 19 个注入能力；7 个必需方法 + 7 个可选方法；`ElementAttr.*` / `ElementTypes.*` 的**枚举值**（`dataSrc` → `'data-src'` 注释）；配置对象字段（`meta`/`render`/`behavior`，含枚举与范围注释）；`Item`/`Page`/`DetailInfo`/`CComic`/`TextContent` 的字段 |
| **hover 文档** | 每个 API 的签名、一句话说明、返回值；对应 `config-spec` 章节号；常见误用（如"`net.request` 是 Promise 形态，不是事件式"） |
| **参数签名** | `helpElAttr(el, name)`、`net.request(options)`、`executeJs(url, code, show?)`、`getTextContent(url, engine)` 等 |
| **诊断** | 拼错方法名、缺少必需方法、字段类型不符、`@deprecated` 的旧式写法（`net.request(...).on(...)` → 提示 `E-CFG-030`） |
| **snippet** | 新建内联配置时注入 7 个必需方法骨架；空数组/空字符串/`null` 三种"无数据"返回值示例 |

实现要点：

1. `config-api.d.ts` 随控制台打包，**不联网获取**；
2. 它是 [config-spec](../03-api/config-spec.md) §3/§8 与 [rest-contract](../03-api/rest-contract.md) §3 的**派生物**——**不得以 d.ts 反推修改规范**；
3. 一致性由单测保障：解析 d.ts 导出的成员名与文档表格逐项比对，缺一即失败；
4. **诊断不替代服务端校验**：保存仍以 `POST /api/validate` 为准（§4.3），两者结论不一致时提示"以服务端校验为准"；
5. 自定义成员（`this.thatGethtml` 之类）不报错：配置对象类型对未知成员开放（索引签名），只对**已知字段的类型错误**报警。

## 5. 调试台

**调试只看数据，不看渲染**：不加载图片、不播放视频、不渲染网页。

### 5.1 结构

```
┌────────────────────────────────────┐
│ 目标：当前草稿 / 已保存版本   [切换] │
│ 方法：[getItems ▾]                  │
│ 参数：                              │
│   URL      [https://example.com/…] │
│   HTML     [ □ 使用粘贴的 HTML ]     │
│   Item     [ {…} ]  (getDetailInfo) │
│   选项     [ ] 强制 WebView  [ ] 返回原始 HTML │
│                      [ 运行  Ctrl+Enter ] │
├────────────────────────────────────┤
│ 结果   JSON 树 / 原始文本  [复制]    │
│ 统计   耗时 812ms · 取页 640 · 解析 40 · 脚本 132 · 命中缓存 ✗ │
│ URL 补全  coverImg  /img/1.jpg → https://example.com/img/1.jpg │
│ 日志    [info] 页面加载：…           │
│ 错误    E-CFG-020 脚本执行超时  ← 高亮 │
└────────────────────────────────────┘
```

### 5.2 交互规则

| 交互 | 行为 |
|---|---|
| 切换方法 | 参数区按 `entry` 显示可用字段（见 [web-admin-api](../03-api/web-admin-api.md) §5.1 表） |
| 目标切换 | 可在「当前草稿」与「已保存版本」间切换，用于对比修改前后 |
| 运行 | `Ctrl/Cmd + Enter`；运行期间按钮变"停止"，可中断（SSE 断开 + 服务端取消） |
| 结果展示 | 默认 JSON 树（可折叠），可切"原始文本"；大结果（>2000 行）自动折叠到二级 |
| 复制 | 复制整段 JSON 或单节点 |
| 深度链接 | 结果中的 `jumpUrl`/`url` 可点，提示"用浏览器打开"（仅提示，不在面板内加载） |
| 历史 | 保留最近 10 次运行结果，可回看（不落盘） |
| **命中人机校验** | 结果区顶部显示"等待设备完成人机校验（域名）…"并持续计时；运行按钮保持"停止"；收到 `challengeResolved` 后自动继续并展示最终结果 |

### 5.3 结果呈现规范

1. **先给结论，再给细节**：顶部一行 `成功 · 24 条 · 812ms` 或 `失败 · E-CFG-021`；
2. **分段耗时**必须展示（取页 / 解析 / 脚本），这是定位性能问题的主要依据；
3. **URL 补全对照**必须展示（`raw` → `resolved`），这是最常见的配置错误来源；
4. **日志与错误分区**，错误置顶并高亮 `code` 与字段路径；
5. 空数组要明确显示 `[] (0 条)`，不能给一片空白（"0 条"与"没跑"必须可区分）。

### 5.4 错误定位辅助

| 错误来源 | 界面表现 |
|---|---|
| 取页失败 | 显示状态码、耗时、是否走了 WebView，并提供"只跑 fetch"按钮 |
| 脚本异常 | 显示 `stack` 首行，点击跳到源码模式对应行 |
| 返回值不合模型 | 高亮不合规的具体字段（如 `detailType`），并列出合法值 |
| 超时 | 显示各阶段耗时，指出卡在哪一阶段 |

## 6. 导入导出与同步

### 6.1 导入

- 方式：拖拽文件 / 选择文件 / 粘贴文本 / 从 URL 拉取（可选）；
- 支持单配置与 bundle（多配置）；
- 导入前先 `POST /api/configs/import`（预校验）→ 展示"将新增 3 个、覆盖 1 个、失败 1 个（含原因）"→ 确认后提交。

### 6.2 导出

- 单配置：`.ghscfg.json`，可选清单/内联/打包三形态；
- 全部：`.bundle.json`；
- 导出前提示"包含脚本源码"。

### 6.3 同步状态（只读）

> **连接参数只在应用端配置**：WebDAV 地址、账号、密码、远端目录、冲突策略、自动同步开关，全部在应用「设置 → 同步」中填写。网页端**不提供任何填写入口，也不会收到凭证**（见 [design.md](../01-product/design.md) §2.6）。理由：连不上的时候，用户还没打开网页。

| 区域 | 内容 |
|---|---|
| 状态 | 是否已配置、远端目录、上次同步时间与结果 |
| 操作 | 测试连接、拉取、推送（实际执行在应用进程内，使用应用内已存凭证） |
| 冲突 | 冲突列表，逐条选择「保留本地 / 保留远端」，提交后由应用按应用端设定的策略落盘 |
| 空态 | 未配置时不显示操作按钮，只给一行指引："请到应用内「设置 → 同步」完成配置" |

### 6.4 界面边界（职责划分）

判断标准（设计文档 §2.6）：**阅读是 App 端唯一主业**。Web 端承担所有"非阅读且复杂"的操作。

| 本界面负责 | 应用端负责 |
|---|---|
| 配置内容编辑、调试运行 | 阅读与播放主路径 |
| 批量导入导出、bundle、排序、批量删除 | 阅读显示设置（主题 / 字号 / 行距） |
| 运行日志（F15）查看与导出 | 当前来源切换、单个配置启用/停用 |
| 缓存治理（F16）：统计与清理 | "清理全部缓存"便捷按钮 |
| 备份与恢复（F20） | Web 服务开关 / 端口 / 绑定 / 令牌 |
| WebDAV 同步动作与冲突决策 | WebDAV 地址与凭证、代理配置 |
| 服务状态与端口（只读展示） | 应用内数据的阅读侧展示 |

**本界面不提供**：端口、绑定、令牌、代理、WebDAV 凭证等设备级设置（见 [web-admin-api](../03-api/web-admin-api.md) §2）。
**应用端不提供**：配置编辑、调试、日志、缓存治理、备份恢复、批量管理。

### 6.5 诊断（日志与缓存）

| 区块 | 内容 |
|---|---|
| 日志 | 级别过滤（debug/info/warn/error）、按来源与时间筛选、关键词搜索、复制、导出 `.txt`、点击跳到对应配置 |
| 缓存 | 总占用、按类型（`html` / `image`）与按来源的占用、命中率；清理支持"全部 / 按类型 / 按来源"三档 |
| 工具条 | 刷新、清空日志（二次确认） |

### 6.6 备份与恢复

| 动作 | 流程 |
|---|---|
| 导出 | 勾选要包含的类别（配置 / 偏好 / 进度 / 收藏 / 历史 / 搜索词）→ 生成 `ghs-repo-<时间>.bundle.json` 下载 |
| 导入 | 拖入或选择文件 → `dry-run` 预览（新增 / 更新 / 跳过各多少）→ 选择 `merge` 或 `replace` → 提交 → 展示逐类别报告与失败明细 |

与 WebDAV 同步的区别：**备份是单文件整包，同步是分片增量**（见 [local-store](../03-api/local-store.md) §5、§7）。

## 7. 状态与提示规范

| 场景 | 呈现 | 时长 |
|---|---|---|
| 保存成功 | 右上角轻提示 + 标题栏去掉"未保存"标记 | 2s |
| 保存失败 | 顶部错误条（含 `code` 与路径），不自动消失 | 手动关闭 |
| 校验警告 | 黄色条，可折叠 | 手动关闭 |
| 请求失败 | 组件内错误态 + 重试按钮 | — |
| 未保存离开 | 二次确认对话框 | — |
| 服务断开 | 全屏遮罩"连接已断开"，每 3s 重试，恢复后自动加载 | — |

**禁用**：`alert()` / `confirm()` 原生弹窗；统一用组件内对话框。

## 8. 快捷键与交互细节

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + S` | 校验并保存当前配置 |
| `Ctrl/Cmd + Enter` | 在调试台运行 |
| `Ctrl/Cmd + K` | 聚焦配置搜索 |
| `Ctrl/Cmd + \` | 折叠/展开调试台 |
| `Esc` | 关闭对话框 / 退出全屏结果 |

其他：

- 编辑区自动记录**本地草稿**（IndexedDB），刷新页面不丢；保存成功后清除；
- 标题栏显示"● 未保存"标记；
- 长时间无操作（30 分钟）提示"服务可能已停止，是否重新连接"。

## 9. 验收清单

- [ ] 新建设置清单形态后，能直接保存并通过校验
- [ ] 表单改动同步到源码视图，源码改坏后表单只读并提示行号
- [ ] 校验返回多条错误时全部展示，点击可跳到对应字段/行
- [ ] `getItems` 试跑返回 JSON 树，含条数、分段耗时、URL 补全对照
- [ ] 粘贴 HTML 试跑可跳过网络，直接验证解析逻辑
- [ ] 脚本抛错时显示 code、路径与 stack 首行
- [ ] 空数组显示 `[] (0 条)` 而非空白
- [ ] 运行中可停止，停止后服务端不再占用引擎
