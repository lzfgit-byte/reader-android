# UI 实现规范

**本文件是"界面结构与交互实现"的唯一权威来源（SSOT）**：设计系统、应用骨架、组件契约、页面结构、状态机、手势与动效、性能预算。

需求是什么在 [design.md](../01-product/design.md) §5；配置怎么驱动 UI 在 [config-spec.md](../03-api/config-spec.md) §3.2。本文件只讲**怎么实现**。

---

## 1. 设计原则

| 编号 | 原则 | 含义 |
|---|---|---|
| U1 | **内容优先** | 界面为内容让位：图片/视频区域最大化，装饰元素降到最低 |
| U2 | **配置驱动** | 卡片尺寸、卡片样式、入口显隐、阅读器默认模式都来自配置；UI 不得硬编码这些值 |
| U3 | **单一骨架** | 所有页面共用同一套骨架（顶栏/内容/底栏/胶囊），保证转场与手势一致 |
| U4 | **状态显式** | 每个数据页必须有 `Loading / Empty / Error / Content` 四态，不允许"白屏" |
| U5 | **可预测** | 相同交互在所有页面表现一致（下拉刷新、触底加载、长按菜单） |

## 2. 设计系统

### 2.1 色彩

| 语义 token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `surface` | `#FFFFFF` | `#121212` | 页面背景 |
| `surfaceVariant` | `#F5F5F7` | `#1E1E1E` | 卡片/输入框底 |
| `onSurface` | `#1A1A1A` | `#EDEDED` | 主文字 |
| `onSurfaceVariant` | `#6B6B70` | `#A0A0A6` | 次要文字 |
| `accent` | `#3B6EF6` | `#7EA0FF` | 强调、可点元素 |
| `accentOn` | `#FFFFFF` | `#0A0A0A` | 强调色上的文字 |
| `danger` | `#D64545` | `#FF7A7A` | 错误、删除 |
| `scrim` | `#00000066` | `#00000099` | 弹层遮罩 |

- 配置可通过 `render.themeColor` 覆盖 `accent`，只影响强调色，不改结构色。
- 对比度要求：正文 ≥ 4.5:1，大面积 ≥ 3:1。

### 2.2 排版

| token | 字号/行高 | 用途 |
|---|---|---|
| `display` | 24/32 | 页面主标题 |
| `title` | 18/26 | 卡片区标题、Sheet 标题 |
| `body` | 15/22 | 正文、评论 |
| `label` | 13/18 | 按钮、标签 |
| `caption` | 11/16 | 角标、时间、辅助信息 |

字体跟随系统；用户字号放大到 200% 时布局不得截断（用 `sp` 且允许换行）。

### 2.3 尺寸与间距

- 间距基准 **4dp**，常用 `4 / 8 / 12 / 16 / 24`。
- 圆角：卡片 `12dp`、按钮 `8dp`、Sheet 顶部 `20dp`、角标 `4dp`。
- 触控目标最小 `48×48dp`。
- 内容区左右安全边距 `16dp`；图片墙边距 `12dp`、卡片间距 `8dp`。
- **顶栏动作按钮的宽度随内容**：Material `TextButton` 自带 `58–64dp` 最小宽度，一行并排四个就会把元素摊满整条顶栏、
  看着处处是空隙。顶栏文字按钮改用「水平内边距 `6dp`、高度仍 `≥48dp`（触控下限）」的紧凑按钮，
  相邻按钮的可见间距落在 `8–16dp`。

### 2.4 层级

| 层 | 内容 | z 序 |
|---|---|---|
| 底 | 内容流 | 0 |
| 中 | 顶栏 / 底栏（可隐） | 10 |
| 上 | 状态胶囊 | 20 |
| 浮 | Sheet / 对话框 / 播放器控制层 | 30 |
| 顶 | Snackbar / 全局提示 | 40 |

## 3. 布局与断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| compact | < 600dp | 单栏内容流；底栏 4 Tab；阅读器/播放器全屏 |
| medium | 600–840dp | 内容流双栏；底栏变侧边导航栏 |
| expanded | > 840dp | 内容流三栏；详情页左图右文 |

横屏时：

- 阅读器与播放器进入**沉浸式全屏**（隐藏系统栏，边缘滑动唤出）；
- 列表页保持竖屏布局，仅增加列数。

## 4. 应用骨架

### 4.1 结构

```
Scaffold
├── topBar        页面标题 + 返回 + 页面级操作（可滚动折叠）
├── content       页面主体（四态容器）
├── bottomBar     BottomNav（Tab 页）/ 播放控制条（全局迷你播放器）
└── overlay
    ├── StatusCapsule   抓取进度与状态提示
    ├── Snackbar        轻提示
    └── MiniPlayer      离开播放器后的悬浮播放条
```

> **人机校验窗口不在这棵 UI 树里**：它是独立 Activity（见设计文档 §8.14），必须能越过当前界面、从任何状态（含后台请求）弹出。

**顶栏只放一行**：

| 位置 | 放什么 |
|---|---|
| 左（导航图标之后，唯一主体元素） | 列表页＝**来源切换**（站点图标 + 名称）；首页在标签态时在来源后跟标签名（**库页不跟**：收藏/历史由底栏高亮表达，顶栏不再重复一遍，只留来源）；详情页＝**内容标题**（单行省略） |
| 右（页面级动作，紧凑排列） | 标签（配置 `getTags` 返回了标签时才出现）、筛选（配置返回了 `urlReplace` 时才出现）、页码、布局切换、搜索（放大镜 → 搜索弹窗） |
| 中 | 留弹性空白，不要用间距均摊把动作推向两侧 |

动作一律用**宽度随内容**的紧凑按钮（见 §2.3）；不得把带最小宽度的 `TextButton` 并排堆在 `TopAppBar` 的 `actions` 里。

| 页面 | 结构 | 状态 | 关键交互 | 注意 |
|---|---|---|---|---|
| 人机校验窗口（独立 Activity） | 顶栏（域名 + 说明）+ WebView + 底部按钮 | 校验中 / 自动通过 / 需手动确认 / 超时 | 完成校验、`我已完成`、`取消` | 只允许同 host 导航；沿用进程级代理；挑战页不写缓存 |

### 4.1.1 WebView 窗口（受管实例）

界面上能看到的三处 WebView 都由**同一个窗口模型**承载（决策见 [ADR-0017](adr/ADR-0017-webview-window-model.md)），不再各自 `new WebView`：

| 窗口 | 界面位置 | 复用策略 | 显隐规则 |
|---|---|---|---|
| `browser` | 「网页浏览」页内容区 | 单例 | 进入页面挂载，离开页面销毁（不再残留实例） |
| `fetch` | 「显示 webview」镜像窗口（右上角入口） | 单例 | 默认无容器；镜像窗口打开时挂载，关闭时摘回 |
| `challenge` | 人机校验 Activity 内容区 | 一次性（**真实设备 UA**） | 每次校验新建，结束销毁；不使用桌面 UA 伪装，也不套桌面 Client Hints（否则与 JS 侧指纹矛盾）；凭证靠共享 Cookie 传递给后续请求 |

不显示的 `engine`（脚本引擎）与 `image`（图片兜底，对象池）没有任何界面，也不允许被挂到界面上。

约定：

- 一个窗口同一时刻只能挂在一个容器里；换容器走 `attachTo` / `detachFromParent`，不手工 `removeView`
- 控制层（Compose）只负责提供容器（`FrameLayout`），不直接持有 WebView
- 窗口关闭后不可复用，再次需要时由 `WebWindows` 重建


### 4.2 底栏由配置决定

底栏 Tab 从 `render.setTags` 推导，映射见 [config-spec](../03-api/config-spec.md) §3.4：

| 配置项 | Tab |
|---|---|
| （固定） | 首页 |
| `收藏` | 收藏 |
| `历史` | 历史 |
| `系统配置` | 设置 |

规则：

- Tab 数量 < 2 时不显示底栏，改用顶栏菜单；
- 切换配置后底栏**重建**（保留当前 Tab 若仍存在，否则回首页）；
- 未启用的入口**不渲染**，不置灰。

> `标签` **不占 Tab**：它是首页的一次「换一批内容」，入口是顶栏的标签图标 + 标签抽屉（见 §5 `TagPickerSheet`）。底栏因此只有首页/收藏/历史三项。

### 4.3 转场

| 场景 | 动效 | 时长 |
|---|---|---|
| Tab 切换 | 淡入淡出 | 150ms |
| 进入详情 | 共享元素（封面）+ 淡入 | 300ms |
| 进入阅读器/播放器 | 上滑 + 淡入 | 250ms |
| Sheet | 底部上滑 | 250ms |
| 返回 | 反向 | 与进入对称 |

### 4.4 返回键（强制）

**返回键永远只退一层，不直接退出应用。** 分两层落地，两层都必须覆盖：

| 层 | 谁负责 | 规则 |
|---|---|---|
| 浮层 | 页面自身 | 抽屉 / Sheet / 对话框先消费返回：关掉浮层，页面不动 |
| 内容页 | `DemoApp` 的 `BackHandler` | 详情、阅读器、单图、播放器、搜索结果、解析中……返回上一级（列表 / 上一话 / 关闭播放器） |
| 二级页 | `AppRoot` 的 `BackHandler` | 引擎自检、设置、网络代理、网页浏览等从主界面打开的独立页：返回主界面 |

约定：

1. **只有主界面**（首页列表、无抽屉、无浮层、无解析中）的返回键才允许退出应用；
2. 新增任何二级页面（新 `Page` 值或新 `Screen` 类型）时，**必须同时接上返回键**，并在 §12 验收清单勾一项；
3. 判断"能不能返回"不要枚举具体页面类型，用「当前是否在根状态」推导——漏一个类型就会变成"按返回直接退出应用"（该缺陷已出现过两次）。

### 4.5 左侧抽屉 = 导航入口（不再内嵌设置表单）

抽屉只放**入口**，不展开设置项本身：点一项就进一个二级页，返回键退回主界面。

| 分组 | 入口 | 去向 |
|---|---|---|
| 设置类 | 外观 / Web 管理 / 网络代理 / 阅读 | 各自独立页（一项一类一页） |
| 数据类 | 备份与恢复 | 独立页（导出走系统「创建文件」，恢复走「打开文件」+ 确认框） |
| 诊断类 | 引擎日志 / 引擎自检 / 网页浏览（可选代理·直连） | 日志面板 / 自检页 / 浏览页 |
| 清理类 | 清除缓存 · <大小> / 清空本站历史 | 确认弹窗 |

约定：

1. 设置项**不再**以表单形式内嵌在抽屉里——抽屉里出现输入框、开关、chip 都算违反本约定；
2. 新增设置项时，先判断它属于已有一页还是需要新页：**新页就要按 §4.4 接返回键**；
3. 抽屉整块可滚动（引擎日志、清缓存跟随滚动），不再单独固定底部。

## 5. 组件规范

| 组件 | 职责 | 状态 | 关键约束 |
|---|---|---|---|
| `ContentCard` | 内容卡片 | 默认/按下/已收藏/加载中/加载失败 | 尺寸由 `imgWidth/imgHeight` 决定（支持 `px`/`dp`/`vw`/`%`）；`cardStyle` 切换三种排布；有 `author` 时在标题下显示一行次要文字 |
| `SiteAvatar` | 站点图标（顶栏来源切换 18dp / 站点选择器 34dp） | 有图标 / 无图标（首字色块） | 取配置 `favicon`，格式支持见 [config-spec](../03-api/config-spec.md) §3.1（位图 / **svg** / `data:` 内联图）；取不到或解不开时露出底下的**首字色块**，不留空位；图标必须由 `AsyncImage` 自己绘制——用 `painter.state` 在外层做分支会因为没人绘制而永远停在 Loading |
| `SitePickerSheet` | 站点抽屉（顶栏来源名 / 抽屉「来源」） | 默认 / 搜索过滤 / 拖动中 | 两列卡片 + 顶部搜索框，当前站点打勾；**长按卡片拖动排序**：拖动中的卡片**换成实心底色（`surfaceContainerHighest`）+ 主色描边 + 8dp 阴影 + 放大 1.03**，并且**严格跟手**——卡片被"拿起来"后贴在手指下随手指移动，越过目标格才换位（同一格不重复移动），槽位处留出空位。动画分两层：**抬起**用 0→1 的 `animateFloatAsState`（140ms `tween`）驱动底色/阴影/缩放，**换位**用 `Modifier.animateItem(placementSpec = tween(160ms))`（`ExperimentalFoundationApi`）让**其它**卡片滑到新格；被拖的那张**不能**加 `animateItem`，它的位置由跟手位移决定，槽位动画叠上去会让人自己"追"着手指漂。四处坑：①跟手位移**每帧从当前格子重算**：`translation = (手指 - 抓取点) - 卡片格子左上角`，**不要**用"手指增量 + 换位差 + 滚动量"去累加——1 帧延迟和重复补偿都会攒成误差，实测拖两行就漂掉一格（卡片跑到手指上方、还会被网格裁掉一块）；②`onGloballyPositioned` 必须留在 `graphicsLayer` **外面**：放进里面时上报坐标会带上本层位移，位移拿上一帧的自己修正自己，卡片会越飞越远直接消失（这两种写法都踩过，现在这条公式是自校正的）；③卡片平时是**透明底**，只加阴影或放大时阴影层会透成一块白板，必须先给抬起态一个实心底色；④阴影与缩放要放在**同一个** `graphicsLayer` 里，拆两层时阴影按未缩放边界绘制，会在边上留一条白边；抬起态是连续量（`lift`），不要写成 `if (dragging)` 的二值切换，否则按下/松手会硬跳。命中判断仍用每张卡片的 `boundsInWindow`（布局坐标，不含位移），**抽屉在独立 Dialog 窗口，必须用窗口坐标**；拖到列表上下边缘 72dp 内自动滚动（`LazyGridState.scrollBy` + `withFrameNanos` 逐帧），滚动量补进跟手位移后按最新位置重新判定目标；松手时用 140ms 把残余位移滑回 0（别直接清，会"啪"地跳一下），再回调 `onReorder(keys)` 落库；搜索框有内容时禁用拖动（子集顺序无法表达整体） |
| `TypeBadge` | 右上角类型角标 | 视频/图片/图集 | 文案 ≤ 4 字符；半透明黑底白字 |
| `CollectStar` | 收藏星标 | 未收藏/已收藏/提交中 | 点击不进入详情（拦截事件） |
| `MarqueeTitle` | 单行滚动标题 | 静止/滚动 | 仅在文本超宽时滚动；页面不可见时暂停 |
| `PaginationBar` | 分页条 | 有分页/无分页 | 当前页高亮；`url` 为空或标记禁用时置灰不可点；引擎不过滤分页项，界面按返回项渲染 |
| `FilterSheet` | 排序筛选面板 | 展开/收起 | 按 `schema` 分组；选中即应用并关闭 |
| `SearchDialog` | 搜索弹窗（首页 / 搜索结果页顶栏放大镜打开） | 默认/搜索中/失败 | **屏幕居中**（不是底部抽屉）：键盘弹出时输入框不被顶到边缘，整块再按 IME insets 上移；打开即聚焦并弹键盘，输入框带一键清空；**右下角「搜索」是提交入口**（关键词为空时置灰），键盘搜索键同效；失败时弹窗不关，错误红字显示在输入框下方，改词即可再提交 |
| `SearchLoadingDialog` | 搜索中的 loading 弹窗 | 搜索中（仅此一态） | 模态：`Dialog` 的 `dismissOnBackPress` 与 `dismissOnClickOutside` 都关掉，切页/重复提交都被拦；文案带关键词，长等待时能看出在搜什么 |
| `TagPickerSheet` | 标签抽屉（首页顶栏标签图标打开） | 默认/选中/**占位** | 三列固定网格；`url` 为空的项渲染为**不可点的占位**（描边空位），**不得丢弃**；当前标签高亮，处在该标签列表时首项为「全部」；标签可能同名同空地址，LazyGrid 的 key 必须用下标——拼「标题#地址」会撞 key 直接崩 |
| `EmptyState` | 空态 | — | 图标 + 一句说明 + 可选操作按钮 |
| `ErrorState` | 错误态 | 可重试/不可重试 | 必须显示错误码与可读原因（见 config-spec §7） |
| `SkeletonGrid` | 加载骨架 | — | 与真实卡片同尺寸，避免跳动 |
| `CommentItem` | 评论条目 | — | 时间 + 文本 + 可选缩略图 |
| `EpisodeSheet` | 分集面板 | — | 当前集高亮；长列表可搜索 |
| `QualityPicker` | 画质切换 | — | 单选，选中即切换并保留进度 |
| `SeekBar` | 播放进度条 | 拖动中/静止 | 拖动时显示预览时间；缓冲显示二级进度 |
| `StatusCapsule` | 抓取状态胶囊 | 空闲/进行中/失败 | 进行中显示百分比；失败点击展开日志 |

## 6. 页面实现要点

| 页面 | 结构 | 状态 | 关键交互 | 注意 |
|---|---|---|---|---|
| 首页 | 顶栏（来源切换 + 标签 / 筛选 / 页码 / 布局 / 搜索）+ 内容流 | 四态 + 分页追加 | 下拉刷新、触底加载、长按收藏、点标签图标开抽屉选标签 | 分页追加失败不得清空已有内容 |
| 搜索 | 搜索弹窗（居中：输入框 + 取消/搜索）+ 搜索中 loading 弹窗 + 结果流 | 空/搜索中/结果/无结果 | 打开即聚焦填词、右下角「搜索」提交、结果页筛选 | 结果页复用首页卡片；筛选面板与普通列表同一套（改的是该次搜索地址，关键词保留）；搜索失败时弹窗不关，错误留在输入框下方 |
| 详情 | 封面头图 + 元信息 + 条目列表 + 相关推荐 | 四态 | 收藏、点标签、条目选择 | 按 `detailType` 跳不同渲染器（§6.1）；图片条目优先 `fullUrl`（原图），失败回落 `url`（展示图） |

### 6.1 渲染器分发

```
detailType ──► mp4 / m3u8 ──► VideoPlayerScreen
           ├─► image ──────► 多图 ? GalleryReaderScreen : SingleImageScreen
           ├─► comic ──────► GalleryReaderScreen（先取目录）
           ├─► text ───────► TextReaderScreen（先取目录，再取正文块）
           ├─► series ─────► SeriesSheet（当前页内弹出）
           └─► win ────────► EmbeddedWebScreen
```

新增渲染器时：在 `:core:designsystem` 注册 `Renderer(id, factory)`，**不得**在导航层写 `when` 硬分支。

## 7. 状态与数据流

### 7.1 单向数据流

```
UI Event ──► ViewModel ──► Repository/Engine ──► UiState(StateFlow) ──► UI
                                   └──► Effect(Channel) ──► 一次性事件（Toast/跳转/播放）
```

规则：

- `UiState` 不可变（`data class` + `copy`），UI 只读；
- 一次性事件走 `Channel<Effect>`，不放进 State（避免旋转重放）；
- 所有耗时调用在 `viewModelScope`，页面销毁即取消。

### 7.2 四态容器

```kotlin
sealed interface UiState<out T> {
    data object Loading : UiState<Nothing>
    data object Empty   : UiState<Nothing>
    data class  Error(val code: String, val message: String, val retryable: Boolean) : UiState<Nothing>
    data class  Content<T>(val data: T) : UiState<T>
}
```

- `Loading` 首次加载显示骨架屏；**分页追加**显示底部加载条，不切四态；
- `Empty` 必须给出"为什么空"（无数据 / 被筛选 / 配置未启用某功能）；
- `Error` 必须带错误码，`retryable` 决定是否显示重试按钮。

### 7.3 分页状态机

```
Idle ──► Loading(first) ──► Content ──► Loading(more) ──► Content
                                 └──► End（无更多）
                                 └──► Error(more)（保留已有内容，底部重试）
```

## 8. 手势规范

### 8.1 阅读器（优先级从高到低）

| 手势 | 行为 | 冲突处理 |
|---|---|---|
| 双指缩放 | 缩放当前页 | 优先级最高，其他手势暂停 |
| 双击 | 2x 缩放切换 | 与单击区分：300ms 内无双击则判定为单击 |
| 左缘（≤ 24dp）上下滑 | 屏幕亮度 | 与滚动冲突时，横向位移 > 纵向则不拦截 |
| 右缘（≤ 24dp）上下滑 | 媒体音量 | 同上 |
| 单击 | 显隐浮层 | — |
| 长按 | 保存图片 | — |

### 8.2 播放器

| 手势 | 行为 |
|---|---|
| 单击 | 显隐控制层 |
| 双击 | 播放/暂停 |
| 左右滑（中部） | 快进/快退（范围显示在屏幕上） |
| 左右滑（两端） | 亮度/音量 |
| 长按 | 3x 临时加速，抬起恢复 |

### 8.3 列表

- 下拉刷新：下拉 > 64dp 触发，阈值内松手回弹；
- 触底加载：距底部 3 个卡片高度时预取；
- 长按：弹出快捷菜单（收藏/复制标题/删除）；
- 滑动删除：横向拖动 > 30% 宽度确认。

## 10. 无障碍与适配

- 全部可交互元素有 `contentDescription`；纯装饰图设 `null` 防止朗读噪音；
- 支持系统字号 200%；支持粗体文本；
- 触控目标 ≥ 48dp，相邻目标间距 ≥ 8dp；
- 不依赖颜色单独传达状态（收藏用"星标 + 形状变化"，不只变色）；
- 布局预留 RTL；
- 平板/折叠屏：`WindowSizeClass` 驱动布局，改变宽度不重建 ViewModel。
